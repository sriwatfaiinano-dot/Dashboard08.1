สูตร KPI ที่ใช้ในแดชบอร์ด

คำนวณจากตัวตั้ง/ตัวหารจริง ไม่เฉลี่ยเปอร์เซ็นต์รายคน
%รับสายจำนวนสายที่รับ ÷ จำนวนโทรออก × 100ใช้กับรวม, 0DAY, 5DAY, CROSS, REORDER และเบอร์ขุด
%ปิดการขายจำนวนออเดอร์ที่ปิดได้ ÷ จำนวนสายที่รับ × 100ใช้กับ 0DAY, CROSS, REORDER และเบอร์ขุด
%ปิด RE รวม(ออเดอร์ RE + LINE + INBOUND) ÷ (รับสาย RE + ออเดอร์ LINE + INBOUND) × 100LINE+INBOUND ใช้คอลัมน์ยอด/Order ที่ยืนยันร่วมกัน
%ปิดรวมออเดอร์ 0DAY+CROSS+RE+เบอร์ขุด+LINE/INBOUND ÷ ลูกค้าที่คุยได้ของช่องทางขายทั้งหมด × 1005DAY ไม่รวมใน %ปิดรวม เพราะไม่มีออเดอร์ปิดการขายในดิป

หมายเหตุการคำนวณ
  • % KPI ระดับ Unit และบริษัทคำนวณจาก “ผลรวมตัวตั้ง ÷ ผลรวมตัวหาร” ไม่ใช่เอา % รายคนมาเฉลี่ย
  • ออเดอร์ที่ใช้คำนวณ %ปิดรวม = Order ของ 0DAY + CROSS + REORDER + เบอร์ขุด + LINE/INBOUND
  • จำนวนลูกค้าที่คุยได้ใน %ปิดรวม = รับสาย 0DAY + CROSS + REORDER + เบอร์ขุด + Order LINE/INBOUND ตามสูตรที่ยืนยัน
  • ช่อง “Order รวม” เดิมในไฟล์ไม่ได้ถูกนำมาเป็นตัวตั้ง %ปิดรวม เพราะสูตรที่ยืนยันให้รวม Order รายช่องทางโดยตรง
  • U1 ฝนแสดง “ไม่มีดิป W1” จนกว่าจะมีข้อมูลโทร/ยอดขายของฝนจริง
